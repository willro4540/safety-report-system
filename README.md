# 시설 안전 민원 신고 관리 프로그램

정부의 **안전신문고** 서비스를 참고하여 만든 시설 안전 민원 신고 데스크톱 프로그램입니다.
안전신문고 앱스토어 버전의 사용자 평가가 낮다는 점에 주목해, 개발자 입장에서 문제를 직접
분석하고 더 나은 사용자 경험을 구현해보기 위해 제작했습니다.

> 2026.06.09 ~ 2026.06.16, 광주인력개발원

## 기술 스택

| 구분 | 내용 |
|---|---|
| 언어 | Python 3.12 |
| GUI | PySide6 (Qt Creator로 UI 설계) |
| 데이터베이스 | MySQL 연동 예정 — 현재는 로컬 JSON 자동 폴백 |
| 구조 | 파일 분리형 (`ui/` 모듈 구조) |

## 구현된 기능

| 기능 | 설명 |
|---|---|
| 로그인 / 회원가입 | bcrypt 암호화, DB/로컬 자동 전환 |
| 아이디 찾기 | 이름+전화번호로 조회, 마스킹 표시 (예: `ip123` → `ip***`) |
| 비밀번호 찾기 | 본인 확인 후 새 비밀번호 재설정 |
| 시민 메인 화면 | DB 연결 상태 실시간 표시(서버연결/로컬모드) |
| 민원 신고 | 유형 선택(8종), 사진 첨부, GPS EXIF 자동 추출 |
| 현장 촬영 | 웹캠 라이브 → 촬영 → 미리보기 → 사용/재촬영 |
| PDF 생성 + 이메일 전송 | QPrinter로 PDF 생성, Gmail SMTP로 담당 메일함에 자동 발송 (접수 완료 안내) |
| 처리 완료/기각 SMS 알림 | 관리자가 상태를 "완료"로 바꾸거나 기각 처리하면 신고자에게 SMS 발송 (Solapi) |
| 신고 내역 조회 | 상태 아이콘 표시(접수/처리중/완료/기각) |
| 관리자 패널 | 전체 신고 목록 조회, 상태 변경, 기각/취소 사유 입력 |
| DB/로컬 자동 전환 | MySQL이 없어도 JSON 파일로 자동 대체 동작 |

## 아직 구현하지 못한 기능

- **MySQL 완전 연동**: 초기엔 Python-MySQL 연동 로직을 직접 구현하려 했으나, 참고했던 교재
  예제가 C# 기반이라 그대로 옮기기 어려웠음. 현재는 JSON 로컬 저장 방식으로 전체 기능이 정상
  동작하도록 구현. → 추후 별도 브랜치에서 DB 컬럼 구조를 정비해 완전 연동 예정.
- **신고 취하 기능**: 시민이 본인이 낸 신고를 직접 취하하는 기능은 시간 부족으로 미구현.
  → `ui/history.py`에 취하 버튼 추가로 보강 예정.

## 실행 방법

```bash
pip install -r requirements.txt
cp .env.example .env   # .env를 열어 실제 Gmail 계정/앱 비밀번호로 채워넣기
python main.py
```

Gmail 발송 계정은 일반 로그인 비밀번호가 아니라 **앱 비밀번호**를 발급받아 사용해야 합니다
(Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호).
